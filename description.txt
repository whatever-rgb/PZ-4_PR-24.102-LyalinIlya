Описание документов

Данный файл содержит информацию о документах, 
размещённых в ветке docs-branch.

Состав ветки:
1. report.txt - отчёт
2. description.txt - данный файл с описанием
3. document.pdf - документ в .pdf формате
Назначение ветки:
Ветка docs-branch создана для хранения документации 
проекта и демонстрации работы с файлами формата .txt и .pdf 
в системе контроля версий Git.
